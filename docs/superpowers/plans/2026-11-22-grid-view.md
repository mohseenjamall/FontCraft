# Grid View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a card grid view of font families, switchable from the header with the list, remembered between runs, as fast as the list.

**Architecture:** Pure helpers (view enum, column math, per-script card glyph) in a new `src/grid.rs` and `samples.rs`, unit tested. Drawing stays in `app.rs` as a second path next to `list()`/`row()`, reusing `FontLoader`, `pick_font`, selection and the details panel. The saved choice lives in `store.rs`.

**Tech Stack:** Rust 2024, eframe/egui 0.37, existing `theme` tokens and `widgets`. egui 0.37 API notes: use `ctx.global_style()`, `run_pass(...)`, `TextEdit::align(Align2)`; read `src/app.rs` and `src/theme.rs` for what is really in use.

**Spec:** `docs/superpowers/specs/2026-11-22-grid-view-design.md`

## Global Constraints

- No new dependency; no animation; colours only via `theme::color`, spacing via `theme::space`; sentence case; no arrow characters in UI text.
- Card 136 px square (`CARD_SIZE`), gap 16 (`theme::space::L`), name area 34 px, card radius `theme::radius::CARD`, card fill `color::CARD` with a 1 px `color::CANVAS_LINE` border; selected card `color::SELECTED`; hover `color::CANVAS_HOVER`.
- Budget: ready <= 2.2 s, working set <= 110 MB, binary <= 7.35 MiB. Only cards on screen are drawn and only their fonts load.
- Gates: `cargo test`, `node scripts/build-no-warnings.mjs`, no new warnings. Work on a new branch `grid-view` cut from `design-system` (the design system is not on `main` yet).

## Review Focus

- Narrow and wide windows: `columns` never returns 0 (width 0, below one card, NaN) and cards never clip or scroll sideways; resizing the details panel changes the column count. Pinned by `columns` tests.
- Fonts without Latin letters or with only ornaments (the AGA Arabesque, 3270 Nerd and Akhbar MT families in this machine's list) show a dimmed fallback glyph through `pick_font`, never blank or tofu. Checked in Task 2 screenshots.
- Virtualization: with 271+ families only the visible rows are drawn (`show_rows` over `ceil(n / columns)` rows) and only their fonts are requested. Pinned by a `visible_rows` test.
- Long names, two-line wraps and Arabic family names stay inside the card width and never overlap the next row.
- Switching view keeps the selection; a missing, empty or unknown saved value means list. Pinned by `View::parse` tests.

## File Structure

- Create `src/grid.rs`: `View`, `columns`, layout constants, `row_count`.
- Modify `src/samples.rs`: `card_glyph`.
- Modify `src/store.rs`: `load_view`, `save_view`.
- Modify `src/widgets.rs`: `segmented`.
- Modify `src/app.rs`, `src/main.rs` (module declaration, `--view grid` flag for screenshots).
- Create `GATES-grid.md`.

### Task 1: Pure helpers

**Files:**
- Create: `src/grid.rs`; Modify: `src/samples.rs`, `src/main.rs` (`mod grid;`)

**Interfaces:**
- Produces: `grid::View { List, Grid }` with `View::parse(&str) -> View` ("grid" maps to Grid, anything else to List, case-insensitive, trimmed) and `View::as_str(self) -> &'static str`; `grid::CARD_SIZE: f32 = 136.0`, `grid::NAME_H: f32 = 34.0`; `grid::columns(avail_width: f32) -> usize` (cards plus gaps, at least 1); `grid::row_count(items: usize, columns: usize) -> usize`; `grid::row_height() -> f32` (`CARD_SIZE + space::S + NAME_H + space::L`); `samples::card_glyph(script: u8) -> &'static str`.

- [ ] **Step 1: Write the failing tests** (in `grid.rs` and `samples.rs` test modules):

```rust
#[test] fn parse_is_forgiving() {
    assert_eq!(View::parse("grid"), View::Grid);
    assert_eq!(View::parse(" Grid\n"), View::Grid);
    for s in ["", "list", "wide", "\u{0}"] { assert_eq!(View::parse(s), View::List); }
    assert_eq!(View::parse(View::Grid.as_str()), View::Grid);
}
#[test] fn columns_never_zero_and_fit() {
    for w in [0.0, 1.0, 100.0, f32::NAN, f32::INFINITY, -5.0] { assert!(columns(w) >= 1, "{w}"); }
    assert_eq!(columns(136.0), 1);
    assert_eq!(columns(136.0 * 2.0 + 16.0), 2);
    assert_eq!(columns(136.0 * 2.0 + 15.0), 1);
}
#[test] fn row_count_rounds_up() { assert_eq!(row_count(0, 4), 0); assert_eq!(row_count(9, 4), 3); assert_eq!(row_count(8, 4), 2); }
// samples.rs
#[test] fn card_glyph_per_script() {
    assert_eq!(SCRIPTS.len(), 16);
    for i in 0..16u8 { assert!(!card_glyph(i).is_empty()); }
    assert_eq!(card_glyph(0), "Aa");
    assert_eq!(card_glyph(4), "\u{639}"); // Arabic ain
    assert_eq!(card_glyph(200), "Aa"); // out of range falls back to Latin
}
```

- [ ] **Step 2: Run to verify it fails.** Run: `cargo test grid samples` Expected: FAIL, items not defined.
- [ ] **Step 3: Implement** the items above. `card_glyph` returns "Aa" for Latin, the Arabic ain for index 4, and for the others the script's own test letter from `SCRIPTS` (index order is fixed by `SCRIPTS`). `columns` uses `((avail + gap) / (CARD_SIZE + gap)).floor()` and `max(1)`, treating NaN/infinite/negative as 1.
- [ ] **Step 4: Run to verify it passes.** Run: `cargo test grid samples` Expected: PASS.

### Task 2: Draw the grid

- Modify: `src/app.rs` (field `view: grid::View` default `List`; `list()` dispatches; new `fn grid()` and `fn card()`), `src/main.rs` (`--view grid` flag calling a `FontApp::set_view`)

**Interfaces:**
- Consumes: Task 1 helpers; `FontLoader::family`, `pick_font`, `all_active`, `widgets::status_dot` (draws an "On" dot right-aligned in a rect).
- Produces: `FontApp::set_view(&mut self, v: grid::View)`.

- [ ] **Step 1: Write the failing test** next to the existing `FontApp::for_test` tests: `grid_drawn_for_visible_rows_only` builds an app with 50 families, calls a pure helper `visible_range(first_row, last_row, columns, total) -> Range<usize>` (add it to `grid.rs` if needed) and asserts the family indexes drawn equal exactly the rows `show_rows` reports, never more. Also `set_view_keeps_selection`: select a family, `set_view(Grid)`, `selected` unchanged.
- [ ] **Step 2: Run to verify it fails.** Run: `cargo test grid` Expected: FAIL.
- [ ] **Step 3: Implement.** `grid()` uses a `CentralPanel` like `list()`; `columns(ui.available_width())`; `ScrollArea::vertical().auto_shrink(false).show_rows(ui, row_height(), row_count, ...)`; per visible row allocate the row rect once and place cards left to right. `card()` paints: fill/border/selected/hover from tokens, the `card_glyph` at 44 px in the family's main face through `loader.family` and `pick_font` (dimmed fallback when the face lacks the glyphs, loading placeholder in `color::CANVAS_LINE`), "N styles" 11 px `color::INK_MUTED` near the bottom of the card, `status_dot` in the top-right when on, and the family name below the card, `color::INK_DIM` 12 px, wrapped to two lines and truncated with an ellipsis inside `CARD_SIZE` width. A click toggles `selected` and resets `selected_face` exactly like `row()`. Add `--view grid` to `main.rs` next to `--select`.
- [ ] **Step 4: Run tests and look.** Run: `cargo test` then `cargo run --release -- --screenshot shots/grid-t2.png --view grid`; also with `--select Arial` and `--text "مرحبا"` (text must not change the cards).
